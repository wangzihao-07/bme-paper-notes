# 生物医学工程（BME）论文精读笔记

> 个人整理的 BME 论文精读笔记库。目标读者是**基础较弱的学习者**（大一新生，具备基础微积分与线性代数），采用**刨根问底**的方式讲解：不满足于"是什么"，一路追问到"为什么"，再用**大白话 + 生活类比**讲清楚，最后落到这个技术对**医生/病人**意味着什么。

## 怎么读这些笔记

- **对象与深度**：为大一新生写。每个公式只说明"表达什么关系"，**不推导**；所有符号、单位、数量级都解释到位。
- **图文结合**：笔记是 BME 论文，靠图说话。每篇笔记都配了论文原图（`images/` 目录），图是理解的关键。
- **归因透明**：笔记里**论文直接说的** vs **我（整理者）基于领域知识补充的分析**（风险、局限、未来方向、设计动机）已明确区分。凡我补充的都会标注"我补充的"，不混入论文观点。
- **结构**：一句话看懂 → 背景动机 → 核心概念 → 逐节精读 → 数学建模 → 风险 / 局限 / 未来方向 → 对比 → Q&A → 自测清单 → 词汇表。
